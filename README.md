[click here](https://www.figma.com/proto/9Y15mNBtrDxo6brrK2uS1X/Untitled?node-id=1-2&t=58ZYT5HduD7nQcNY-1)
## Project Description
This project focuses on designing a HackerRank login page interface using Figma. The design follows UI/UX principles and includes a structured layout with input fields, buttons, and navigation links for user authentication.

## Tool Used
- Figma (Interface Design)

## Design Steps

1. Create a new project in Figma and set up a desktop frame (1440 x 1024 px).
2. Add a white background and place the HackerRank logo at the top center.
3. Design the login form including:
   - Email input field ("Enter your email")
   - Password input field ("Enter your password")
   - Eye icon for password visibility.
4. Create a login button with HackerRank green color (#2EC866).
5. Add navigation links:
   - Forgot Password?
   - Sign Up
6. Align all elements using Auto Layout.
7. Export the design as PNG/JPG.

## Features
- Clean UI layout
- Centered login form
- User-friendly design
- HackerRank-inspired interface

## Output
HackerRank login page interface prototype created in Figma.
